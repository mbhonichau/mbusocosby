## Featured Projects

### ⛈️ Storm Shield (IBM Z Datathon 2024)
- **Overview**: Machine learning system designed to predict severe weather events and assess their impact on water and sanitation infrastructure in South Africa.
- **Problem Statement**: Addresses water contamination, flooding, and waterborne disease risks during heavy rainfall and drought events.
- **Tech Stack**: IBM Data Science & ML Platform, Public Datasets (Weather, Water Quality, Infrastructure Strength), IoT Devices, Predictive Analytics, Community Engagement Tools.

### 🏥 Healthcare Disease Detection & Resource Allocation Model (DIRISA 2024 - CSIR Datathon Top 4)
- **Overview**: Dual-focused machine learning system and Flask web service built for South Africa's healthcare system.
- **Key Capabilities**:
  1. **Early Disease Detection**: Predicts ICD-10 disease codes based on symptoms and demographics using `RandomForestClassifier`.
  2. **Resource Allocation**: Predicts ICU bed and ventilator necessity to eliminate hospital bottlenecks.
  3. **Treatment Cost Prediction**: Estimates patient treatment costs using `RandomForestRegressor`.
- **Tech Stack**: Python, Flask REST API (`app.py`), Scikit-Learn, Joblib, Pandas, StandardScaler, Power BI Dashboards.
- **Data Sources**: Altron Medical Records, OpenStreetMap GIS Data, NICD COVID-19 Data, Stats SA Demographic Data.
