    Storm Shield: Severe Weather & Water/Sanitation System

    Machine Learning-Driven Climate Resilience & Infrastructure Management in South Africa

    Problem Statement

    Even though weather forecasts have improved, people in South Africa still struggle with water and sanitation during extreme weather like heavy rains and droughts. These challenges often lead to flooding, dirty water, and higher risks of diseases that spread through water.

    Innovative Solutions

    This project aims to create a system that uses machine learning to predict severe weather and understand how it affects water and sanitation systems. By using IBM’s tools and public data like past weather reports, water quality records, and infrastructure strength, the system will help manage water resources better. It will also provide real-time updates and predictions to prepare communities and make their water and sanitation systems more resilient.

    Project Objectives

    • Develop an ML System: Create predictive models using machine learning to forecast severe weather events.
    • Analyze Impact: Evaluate and quantify severe weather effects on local water availability and sanitation infrastructure.
    • Real-Time Community Alerts: Deliver actionable updates and early warnings to communities to reduce disease risk and flooding.

    DIRISA Datathon (2024)

    Healthcare Disease Detection & Resource Allocation Model

    AI-Driven Predictive Healthcare System & Resource Optimization for South Africa

    Disease Detection
    ICD-10 Code Classification
    Resource Allocation
    ICU & Ventilator Forecasting
    Cost Prediction
    Random Forest Regressor
    Flask Web API
    JSON Inference Engine

    Problem Statement

    South Africa’s healthcare system faces critical challenges, including resource shortages, delayed outbreak responses, and inefficient resource allocation. Hospitals lack staff, beds, and medications, while patients in underserved areas struggle with limited access to care. Healthcare workers face burnout due to high workloads, and fragmented data systems hinder timely government responses to diseases like tuberculosis and COVID-19.

    Proposed Solution

    Early Disease Detection
    Predicts specific ICD-10 codes and medical conditions early based on symptom severity, patient history, and demographics.
    Resource Allocation Optimization
    Predicts required ICU beds, ventilator usage, and treatment costs to prevent hospital bottlenecks.

    Flask Web Application & API Simulation

    Live JSON prediction endpoint example (/predict API):

    // Sample JSON Request Payload
    { "age": 50, "gender": "Female", "icd_code": "I00", "symptom_severity": "Medium", "treatment_duration": 10 }
    // Simulated Model Prediction Response
    {
      "predicted_icd": "I00 (Acute Rheumatic Fever)",
      "predicted_icu": 0,
      "predicted_ventilator": 0,
      "predicted_cost": "R3,500.00"
    }

    Power BI Analytics Dashboard

    Integrated executive dashboard for hospital administrators tracking capacity, outbreak trends, and cost efficiency:

    ICU Bed Occupancy Real-Time Forecast
    Disease Code Trends ICD-10 Distribution
    Treatment Cost Variance Budget Allocation

    Data Sources

    • Altron Medical Records: Anonymized clinical and patient history database.
    • OpenStreetMap GIS Data: Spatial data mapping regional healthcare facility access.
    • NICD COVID-19 Data: Communicable disease outbreak statistics.
    • Stats SA Demographics: Regional population metrics and risk stratification.

    Model Training & Architecture

    • Treatment Cost: RandomForestRegressor trained on scaled financial metrics.
    • Disease Classification: RandomForestClassifier mapping multi-label ICD-10 codes.
    • Resource Allocation: Binary classifier predicting ICU and Ventilator necessity.
    • Model Persistence: Serialized using joblib (.pkl binaries).
    • Backend Server: Flask microservice handling HTTP POST requests.

    Impact & Scalability

    Impact: Reduces healthcare worker burnout, improves clinical outcomes, and guarantees equitable resource distribution for rural & underserved populations.

    Scalability: Highly adaptable for regional expansion, diverse health datasets, and cloud deployment.

    Challenges & Considerations

    • Data Quality: Cleaned & preprocessed missing data using Pandas & StandardScaler.
    • Privacy & POPIA: Rigorous anonymization of patient records conforming to healthcare laws.
    • Cloud Infrastructure: High-availability deployment for real-time decision support.
